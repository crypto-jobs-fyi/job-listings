# Job Finder

A modern job search platform for **AI**, **Crypto**, and **FinTech** industries, built with Svelte 5 and Vite.

> **✨ NEW**: Dynamic category system! Add new job categories (DeFi, Gaming, Web3, etc.) by editing one config file. See [DYNAMIC_CATEGORIES.md](DYNAMIC_CATEGORIES.md) for details.

## Features

- 🔍 **Multi-page Search**: Browse jobs by industry (Crypto, AI, FinTech) and type (active, new job listings, companies)
- 🎯 **Dynamic Categories**: Easily add new job categories with automatic page generation
- 🔐 **Email Authentication**: Secure login with verification codes (Resend + Upstash Redis)
- ⭐ **Favorites Management**: Save jobs with authentication and persistent storage
- 🏢 **Company Directory**: Browse companies by industry with logos and links
- 📱 **Mobile Responsive**: Touch-friendly UI with responsive design
- ⚡ **Fast Search & Filtering**: Multi-term search by company, location, and title
- 📈 **Job History Charts**: View total and per-company job trends on company pages
- 🔗 **Job Sharing**: LinkedIn share integration and QR codes
- 📊 **Analytics**: Vercel Analytics integrated
- 🏗️ **Type-Safe**: Full TypeScript support with strict mode
- 🧪 **Tested**: Vitest unit tests and Playwright desktop/mobile E2E coverage
- 🛡️ **Resilient Data Loading**: Runtime validation, 15-second request timeouts, TTL caching, and in-flight request deduplication
- 📝 **SEO-Ready**: Complete meta tags, Open Graph, structured data

## Adding New Job Categories

Want to add "DeFi", "Gaming", or other job categories? It's easy!

1. Add the category and its jobs, companies, current-count, new-jobs, and history endpoints to `categories.config.js`.
2. Run `npm run generate` to update generated entry points, constants, Vite inputs, and SEO files.
3. Extend the typed category/store/service/page mappings for the new category; the current data loaders explicitly support Crypto, AI, and FinTech.
4. Run `npm run test`, `npm run build`, and relevant E2E coverage before merging.

See the complete guide: **[DYNAMIC_CATEGORIES.md](DYNAMIC_CATEGORIES.md)**

### E2E Testing Details

Before running Playwright tests for the first time, you may need to install the required browsers:

```bash
npx playwright install
```

The tests start the Vite development server from `playwright.config.ts` and run against Desktop Chrome and Mobile Chrome projects. CI enables fully parallel execution with two workers:

```bash
CI=1 npx playwright test --workers=2
```

## Key Patterns

### Store Subscriptions

Always use `onMount()` with proper cleanup:

```javascript
import { onMount } from 'svelte';
onMount(() => {
  const unsubscribe = favorites.subscribe((favs) => {
    // Handle updates
  });
  return unsubscribe;
});
```

### Job Deduplication

Jobs are deduplicated using `makeJobId()`:

```typescript
const id = makeJobId(job); // "${company}-${title}-${location}".toLowerCase()
```

### Data Loading

Job and company stores call services rather than external endpoints directly. `fetchJSON()` validates responses before storing them, applies a 15-second timeout, deduplicates concurrent requests, and caches successful results for five minutes. The jobs store exposes `loading`, `error`, and `loadedAt` status for each jobs and companies resource.

### Favorites (Map-based)

Favorites store returns a `Map<string, FavoriteJob>`:

```typescript
const ids = new Set(Array.from(favs.keys()));
const jobs = Array.from(favs.values());
```
